# Cuatro capas, un mismo mar · Parte 2

Story map web del avance del proyecto S-100 en el CIOH-SOMO (DIMAR): carta S-101 propia, batimetría S-102, nivel del mar S-104 y corrientes S-111 desplegadas juntas en ShoreECDIS.

- `index.html`: página completa (HTML, CSS y JavaScript con Three.js r128 desde cdnjs).
- `media/`: fragmentos de video y pósters de ShoreECDIS 2.1.0.

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.
